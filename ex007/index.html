Pincipais formatações

Vamos começar falando sobre negrito

A forma semãntica de utilizar a tag negrita é utltilizando o comando <strong>

exemplo: Eu quero

E a forma não semância seria utilizando o comando <B>

Exemplo: eu posso

Agora iremos falar sobre o itálico

A forma semântica de utilizar o itálico é a ultilização do comando <em>

Exemplo: eu quero

A forma não semântica de utilizar o itálico seria a utilização da tag <i>

Exemplo:eu posso

Falando sobre a ultilização da marcação de texto

Usaremos o comando <mark>

Exemplo: Eu quero eu posso

Entrando na parte de dimuir palavras para que elas tenham de certa forma um destaque

A tag que deve ser utilizada seria a <small>

Exemplo: Eu quero eu posso

Quando o assunto é texto com risco de correção

A forma semântica de fazer esse texto é utilizando o comando <del>

Exemplo: eu quero eu posso

Caso você precise de uma linha sublinhando as palavras

É ultilizado a tag <ins>

Exemplo: eu quero eu posso

Entrando no assunto das letrinhas flutuantes tanto em cima quanto em baixo

elas são chamadas de Sobrescritos e Subscritos

Tags sobrescritas

São tags que diminuem as letras e as fazem flutuar, a tag para esta execução é o comando <sup>

Exemplo: x = 32 + 5

Agora as tags subescritas

São tags que também diminuem as letras mas ao invés de flutuar elas ficam no piso da minha, através da utilização da tag <sub>
